## ✨ Core Features (Implemented)
- [x] **Vanilla Frontend Architecture**: Built with pure HTML/CSS/JS. No third-party frameworks, ultra-lightweight, and extremely low performance overhead.
- [x] **Custom Lexicon Import**: Supports importing and switching different text materials (e.g., essays, classic poems).
- [x] **Real-time Metrics**: Accurately tracks typing time (seconds), real-time speed (WPM/Characters per minute), and error rate.
- [x] **IME-Safe Logic**: Perfectly adapted for Chinese Input Methods. Pinyin typing process does not count towards the character count and is not judged as an error.
